# Bank Marketing Project
Απαλλακτική εργασία του μαθήματος Διαχείρισης Δεδομένων Μεγάλης Κλίμακας

## Θέμα

Πρόβλεψη εγγραφής πελατών σε τραπεζική προθεσμιακή κατάθεση με χρήση τεχνικών Data Mining και Big Data Processing.

## Dataset

Bank Marketing Dataset.

## Περιεχόμενα repository

- `01_bank_marketing_project.ipynb`: Jupyter Notebook με τον κώδικα της εργασίας.
- `Report_22390114.pdf`: Γραπτή εργασία.
- `Presentation_22390114`: Παρουσίαση PowerPoint.

## Τεχνικές που χρησιμοποιήθηκαν

- Data preprocessing
- Exploratory Data Analysis
- Decision Tree
- Linear SVM
- Naive Bayes
- Neural Network
- K-Means Clustering
- PySpark Random Forest

## Αξιολόγηση μοντέλων

Τα μοντέλα αξιολογήθηκαν με Accuracy, Precision, Recall, F1-score και ROC-AUC.  
Το καλύτερο classification model ήταν το Decision Tree, καθώς πέτυχε το υψηλότερο F1-score.
